# phred_score.py 사용 설명서

## 1. 개요

`doc/phred_score.py` 는 FASTQ 의 **품질 문자열(4번째 줄) 하나**를 받아서

- 각 위치의 **품질 점수(Phred score, Q)** 와 **오류 확률**을 표로 출력하고,
- 전체 위치의 **점수 합계와 평균 품질 점수**를 계산하는 스크립트이다.

표준 라이브러리(`sys`)만 사용하므로 별도 설치 없이 실행된다.

## 2. 품질 점수 계산 원리 (Phred+33)

FASTQ 의 품질 문자열은 각 염기의 품질 점수를 문자 하나로 바꿔 적은 것이다.
현재 대부분의 FASTQ(Illumina 1.8 이상)는 **Phred+33** 인코딩을 쓴다.

```
Q = (문자의 ASCII 코드) - 33
오류 확률 P = 10^(-Q/10)
```

| 문자 | ASCII | Q | 오류 확률 | 의미 |
|------|-------|---|-----------|------|
| `#`  | 35    | 2  | 0.6310 | 거의 믿을 수 없음 |
| `+`  | 43    | 10 | 0.1    | 10번에 1번 틀림 |
| `5`  | 53    | 20 | 0.01   | 100번에 1번 틀림 |
| `?`  | 63    | 30 | 0.001  | 1000번에 1번 틀림 |
| `I`  | 73    | 40 | 0.0001 | 10000번에 1번 틀림 |

## 3. 사용법

lab11 폴더 안에서 실행한다.

```bash
cd lab11
python3 doc/phred_score.py [품질 문자열]
```

- 품질 문자열을 **생략하면** 예제 문자열 `IIIIIIII#####IIIIIIIIII` 을 사용한다.
- 품질 문자열을 **직접 줄 때는 작은따옴표 `' '` 로 감싼다.**
  `#` 은 셸에서 주석 기호이고, `!`·`*`·`&` 등도 셸이 다르게 해석하기 때문이다.

## 4. 출력 항목 설명

| 항목 | 설명 |
|------|------|
| 위치 | 서열에서 몇 번째 염기인지 (1부터 셈) |
| 문자 | 품질 문자열의 해당 문자 |
| ASCII | 그 문자의 ASCII 코드 (`ord()` 결과) |
| Q | Phred 품질 점수 = ASCII − 33 |
| 오류확률 | 그 염기를 잘못 읽었을 확률 = 10^(−Q/10) |
| 점수 합계 | 모든 위치의 Q 를 더한 값 |
| 평균 품질 점수 | 점수 합계 ÷ 길이 (소수점 둘째 자리까지) |

## 5. 예제 결과 해석

- `I` 18개 × 40점 + `#` 5개 × 2점 = **730점**, 730 ÷ 23 = **평균 31.74**
- 평균만 보면 Q30 이상이라 괜찮아 보이지만, **9~13번째 염기 5개는 Q=2(오류 확률 약 63%)** 로 사실상 믿을 수 없다.
- 그래서 품질은 **평균 하나만 보지 말고 위치별 점수를 함께 확인해야 한다.**
  (FastQC 의 "Per base sequence quality" 그래프를 보는 것과 같은 이유이다.)

## 6. 코드 구조

| 함수 | 하는 일 |
|------|---------|
| `phred_scores(quality)` | 품질 문자열을 받아 각 위치의 Q 점수 리스트를 돌려준다 |
| `main()` | 명령줄 인자를 읽고, 위치별 표와 합계·평균을 출력한다 |

다른 스크립트에서 함수만 가져다 쓸 수도 있다.

```python
from phred_score import phred_scores

scores = phred_scores("IIII####")
print(scores)                     # [40, 40, 40, 40, 2, 2, 2, 2]
print(sum(scores) / len(scores))  # 21.0
```

## 7. 주의할 점

- **Phred+33 전용**이다. 아주 오래된 Illumina(1.3~1.7) 데이터의 Phred+64 형식에서는 점수가 31만큼 크게 나온다.
- **품질 문자열 한 줄만** 처리한다. FASTQ 파일 전체를 처리하려면 `src/qual_summary.py` 를 사용한다.
- 빈 문자열 `''` 을 주면 길이가 0이라 평균을 낼 때 `ZeroDivisionError` 가 난다.
