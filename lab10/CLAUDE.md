# lab10 규칙

## NCBI 에서 서열을 받을 때
- wget 과 E-utilities 를 쓴다. 주소는 반드시 큰따옴표로 감싼다.
- 반복해서 받을 때는 요청 사이에 sleep 1 을 넣는다.
- 유전자 하나를 받을 때는 [SLEN] 으로 길이를 제한한다.
- 받은 파일마다 VERSION 과 ORGANISM 을 확인하고 알려 준다.
- 검색 결과가 없으면 검색어를 바꾸지 말고 먼저 알려 준다.

### 오늘 겪은 일에서 더한 규칙
- 검색 결과가 0개일 때 엽록체 유전체 전체에서 구간을 잘라 받는 식으로
  방법을 바꾸지 않는다. (인삼 rbcL 을 MT416077 REGION: 57343..58800 으로
  잘라 받은 일이 있었다.) seq_start, seq_stop, rettype=ft 는 내가 허락할 때만 쓴다.
- 종마다 esearch 의 Count 와 고른 Id 를 표로 먼저 보여 준다.
- 다운로드 명령은 src/ 아래 스크립트로 저장해서 나중에 어떤 주소를 썼는지 확인할 수 있게 한다.
- 받은 레코드의 DEFINITION 에 "complete genome" 이 있는데 길이가 짧으면 알려 준다.
- 접근번호는 실제 검색 결과에서만 가져온다. 지어내지 않는다.
